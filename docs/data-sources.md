# 数据来源

统计基于2026-11-03的v0.5.0快照。条目数不等同于存档路径覆盖数。

| 内容 | 来源 | 当前快照 |
|---|---|---|
| 游戏目录与存档/配置路径模板 | PCGamingWiki | 52,202个条目，其中15,266个含任一系统路径模板 |
| 官方本地化名称 | Steam商店API | 49,095条查询记录，含无中文名、商品不存在等结果 |
| 游戏译名 | 小黑盒 | 40,554条查询记录，含查过但无名称的结果 |
| 库外游戏名称 | Steam商店API | 3,429条名称记录，不计入游戏目录总数 |
| 修改器目录 | 风灵月影主站、历史归档、小幸 | 765 + 464 + 55，共1,284条，搜索和匹配时去重 |
| 游戏封面 | 本地缓存、Steam、EXE图标、SteamGridDB | 按需获取 |

## 存储与更新

游戏目录使用独立的本地采集管道。`scripts/pcgw/`包含PCGamingWiki抽取和增量同步工具，`scripts/db/`包含结构迁移与合并工具。
名称写入来源表后，按既定优先级合并到游戏目录：中文优先小黑盒、其次Steam官方；英文优先Steam官方，其次小黑盒英文标题和PCGamingWiki标题。名称原样保存，匹配时才进行归一化。

开发全量库保留采集原始响应。发布副本裁去原始响应表，以`gm-database.db`附件分发，不进入Git仓库；应用内可更新数据库。发布附件提供0.3/0.4旧列名兼容，原始名称和游戏条目不变。
名称维护采集与本机调度工具保留在维护者本地，应用不会在后台运行采集器。

修改器主站目录以`gm-trainers-fling.json`附件更新；历史归档和小幸目录随安装包提供。小幸条目打开外部下载页面。

## 使用边界

- 路径模板非空不代表当前机器上存在有效路径；缺失或失效的路径可通过自定义游戏补充。
- Steam榜单用于确定采集顺序，不直接产生存档路径。
- 历史查询并非全部保存了完整原始响应；来源记录数不等于有效中文名称数。
- 游戏名称与存档路径的版权归原来源所有；项目与上述数据提供方无隶属或合作关系。许可说明见[项目README](../README.md#许可)。

字段覆盖与历史快照统计见[数据库报告](database-report.md)。
