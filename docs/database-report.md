## 数据职责

games 保存最终采用的名称和目录字段；name_sources/steam_names/extra_names 保留各来源明细。
开发全量库保留原始响应；发布数据库裁去原始响应表，通过 Release 附件分发。
发布副本增加旧版列的虚拟别名，不重复制名称数据。原始源库不受导出影响。

名字来源及采集方式见 [data-sources.md](data-sources.md)。

## 验证边界

SQLite可读、字段契约和计数检查不等同于逐游戏验证存档路径。没有模板或模板失效的游戏仍需自定义路径。
繁体名通过既定繁简检测规则筛查，不把规则通过率写成人工翻译准确率。
