# Game Manage Center（游戏管理中心）

**游戏管理中心**：统一管理游戏的存档、修改器与 MOD。存档管理之外，
修改器管理已完整接入——内置风灵月影修改器目录，支持中英文搜索、一键下载安装、
启动与就地更新。

> 架构：Tauri 2（Rust 引擎 gm-core）+ React 19 + TypeScript + Tailwind 4

## 功能（存档管理）

- **本机扫描**：识别 Steam / Epic / GOG / EA / Rockstar / 育碧 / 战网 库根目录与安装游戏，
  结合 5.2 万条游戏存档路径库定位存档（支持多账号路径与通配模板）
- **备份**：单游戏或批量一键备份；可选 zip 压缩；语义子目录（存档/设置/注册表）；
  同一分钟内可连续多次备份
- **自动备份**：全局开关——存档文件变化即备份（10 秒冷却去抖）+ 检测到游戏退出时备份
- **恢复**：智能冲突检测（本地比备份新时提示确认），注册表条目一并还原
- **备份管理**：滚动轮换上限、永久固定、删除、备份位置迁移
- **深度扫描**：全库解析找回已卸载游戏的残留存档
- **自定义游戏**：手动添加任意路径/注册表项
- **系统托盘**：关窗可驻留后台，托盘菜单恢复/退出（行为可在设置中切换）

## 功能（修改器管理）

- **目录搜索**：内置风灵月影（FLiNG Trainer）修改器目录（750+ 游戏、2500+ 安装包），
  游戏名中英文均可检索；模糊多策略搜索（子串/缩写/拼音桥接/纠错）按相关度排序
- **联动匹配**：按存档页扫描到的已安装游戏，精确列出每款游戏可用的修改器
- **一键下载安装**：多连接分段并行下载提速，点击即见进度反馈；安装为
  「游戏 / 版本包」两层目录 + 自述清单，防重复下载，失败不留半成品
- **已安装管理**：启动（自动弹 UAC 提权）、打开目录、删除、就地更新（先装新包后删旧包）
- **目录在线更新**：从发布页拉取最新目录，完整校验通过才替换本地
- **Defender 白名单助手**：一键把修改器目录加入排除项，避免杀软误删

## 更新体系

- **软件更新**：按设定频率（每次启动 / 7 天 / 30 天 / 从不）自动检查新版本
- **存档数据库更新**：应用内一键拉取最新 PCGamingWiki 数据库快照，校验后原子替换
- **修改器目录更新**：应用内一键拉取最新目录，完整校验通过才替换并热重载

## 路线图

- [x] **存档管理**——扫描 / 备份 / 恢复 / 自动备份（v0.1.0）
- [x] **修改器**——风灵月影目录搜索、下载安装、启动与更新（当前版本）
- [ ] **MOD**——安装、版本管理与冲突排查

引擎层 `gm-core` 的模块注册表（`module.rs`）为各模块预留了统一接入接口，
后续来源与模块即插即用。

## 开发

```bash
npm install
npm run tauri dev    # 开发运行
npm run tauri build  # 打包安装程序（NSIS，向导随系统语言显示中/英文）
```

引擎单元测试：

```bash
cd src-tauri
cargo test -p gm-core
```
