# Game Manager

一个**游戏管理中心**：统一管理游戏的存档、修改器与 MOD。当前版本聚焦**存档管理**——
自动扫描本机游戏（Steam / Epic / GOG / EA / Rockstar / 育碧 / 战网），按 PCGamingWiki
数据库解析存档路径，支持手动/自动（文件监控、游戏退出时）备份、智能恢复、备份轮换与永久固定。

> 架构：Tauri 2（Rust 引擎 gm-core）+ React 19 + TypeScript + Tailwind 4

## 功能（存档管理）

- **本机扫描**：识别 Steam / Epic / GOG / EA / Rockstar / 育碧 / 战网 库根目录与安装游戏，
  结合 5.2 万条游戏存档路径库定位存档（支持多账号路径与通配模板）
- **备份**：单游戏或批量一键备份；可选 zip 压缩；语义子目录（存档/设置/注册表）；
  同一分钟内可连续多次备份
- **自动备份**：全局开关——存档文件变化即备份（10 秒冷却去抖）+ 检测到游戏退出时备份
- **恢复**：智能冲突检测（本地比备份新时提示确认），注册表条目一并还原
- **备份管理**：滚动轮换上限、永久固定、删除、备份位置迁移
- **深度扫描**：全库解析找回已卸载游戏的残留存档
- **自定义游戏**：手动添加任意路径/注册表项
- **系统托盘**：关窗可驻留后台，托盘菜单恢复/退出（行为可在设置中切换）

## 路线图

- [x] **存档管理**——扫描 / 备份 / 恢复 / 自动备份（当前版本）
- [ ] **修改器**——修改器的管理、更新与一站式启动
- [ ] **MOD**——安装、版本管理与冲突排查

应用内三个模块的导航已就位，修改器与 MOD 显示为"规划中"；引擎层 `gm-core`
的模块注册表（`module.rs`）预留了统一接入接口，后续模块即插即用。

## 开发

```bash
npm install
npm run tauri dev    # 开发运行
npm run tauri build  # 打包安装程序（NSIS，向导随系统语言显示中/英文）
```

引擎单元测试：

```bash
cd src-tauri
cargo test -p gm-core
```
